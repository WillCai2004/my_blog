# Algorithmic Analysis

# Analytical Aspects:

  1. Time Complexity (Focused aspects)
  2. Space Complexity

# Analytical Method:

  1. count the total number of execution steps
  2. count the maximum number of steps for the worst-case

# Example: Insertion Sort Algorithm

For the worst case, the list needed to be sorted should starts with the biggest element, and descending to the smallest element:

Initial Case:

1 2 ... n-2 n-1 n
n n-1 ... 3 2 1

After one insertion (1 comparison, 1 shift)

1 2 ... n-2 n-1 n
n-1 n ... 3 2 1

After one insertion (2 comparisons, 2 shifts)

1 2 ... n-3 n-2 n-1 n
n-2 n-1 n ... 3 2 1

...and so on

  • the nth insertion need n-1 comparisons and n-1 shifts
  • Time complexity: 2⋅∑i=1ni=2⋅n(n+1)2=n(n+1)2 \cdot \sum_{i=1}^n i = 2 \cdot \frac{n(n+1)}{2} = n(n+1)2⋅∑i=1n​i=2⋅2n(n+1)​=n(n+1)

# Efficiency of Algorithms

  • Given problem P, let's assume we get two algorithms. A and B.
  • A is more efficient than B iff A's worst-case running time has a lower "order of growth" than B's.
