# Algorithms Design

# There are three major techniques of designing algorithms:

# 1. Divide-and-Conquer

  1. Divide: change/divide the original problem into sub-problems
  2. Conquer: if the sub-problem size is small enough, solve it directly
  3. Combine: combine the solutions of sub-problems into solution to the original problem

# Example: Merge Sort Algorithm

Merge-Sort(A, p, r) // A[p...r]
    if p == r then
        // Base case: array has only one element, no need to sort.
        return
    else
        q = (p + r) / 2 // Find the middle index
        Merge-Sort(A, p, q)     // Recursively sort the left half
        Merge-Sort(A, q + 1, r) // Recursively sort the right half
        Merge(A, p, q, r)       // Merge the sorted halves

Merge(A, p, q, r)
    // Step 1: Calculate the sizes of the two halves
    n1 = q - p + 1            // Size of the left half
    n2 = r - q                // Size of the right half

    // Step 2: Create temporary arrays for the left and right halves
    Let L[1..n1 + 1] and R[1..n2 + 1] be two new subarrays

    // Step 3: Copy data into the temporary arrays
    for i = 1 to n1 do
        L[i] = A[p + i - 1]   // Copy left half into L
    for j = 1 to n2 do
        R[j] = A[q + j]       // Copy right half into R

    // Step 4: Add sentinel values (∞) to signal the end of the arrays
    L[n1 + 1] = ∞
    R[n2 + 1] = ∞

    // Step 5: Merge the two sorted subarrays back into A[p...r]
    i = 1
    j = 1
    for k = p to r do
        if L[i] ≤ R[j] then
            A[k] = L[i]
            i = i + 1
        else
            A[k] = R[j]
            j = j + 1

# Recurrence Equation:

  • When an algorithm contains a recursive call to itself, we use ∼ to describe the overall running time of the problem in terms of the running time of smaller size sub-problems.
  • These kinds of equation is called as "got ~"
  • Using "Merge Sort" as an example:
    • T(n)=T(n2)+T(n2)+Θ(n)=2∗T(n2)+Θ(n)T(n) = T(\frac{n}{2}) + T(\frac{n}{2}) + \Theta(n) = 2*T(\frac{n}{2}) + \Theta(n)T(n)=T(2n​)+T(2n​)+Θ(n)=2∗T(2n​)+Θ(n)
    • T(n)=T(n2)+T(n2)+Θ(n)=2∗T(n2)+Θ(n)T(n) = T(\frac{n}{2}) + T(\frac{n}{2}) + \Theta(n) = 2* T(\frac{n}{2}) + \Theta(n)T(n)=T(2n​)+T(2n​)+Θ(n)=2∗T(2n​)+Θ(n)

# Example: Quick Sort Algorithm

QuickSort(A, p, r)
    if p >= r
        // Base case: do nothing
        return
    else
        q = Partition(A, p, r) // Partition the array and get the pivot index
        QuickSort(A, p, q - 1) // Recursively sort the left sub-array
        QuickSort(A, q + 1, r) // Recursively sort the right sub-array

Partition(A, p, r)
    x = A[r]       // Pivot is the last element
    i = p - 1      // Initialize the partition index

    for j = p to r - 1
        if A[j] ≤ x
            i = i + 1
            Swap A[i] with A[j] // Move smaller elements to the left

    Swap A[i + 1] with A[r]     // Place pivot at its correct position
    return i + 1                // Return the pivot index

  • Array: A=[2,8,7,1,3,5,6,4]

  • Quick Sort steps:

    1. Keep moving j to the right until finding the first element ≤ x, j stops.
    2. when j stops, i moves one position to its right
    3. swap elements at index i with element at index j
    4. continue the three steps above until j == r-1

  • The key idea of Partition is to divide the original array into serval areas

  • Recurrence equation for Quick Sort

    1. Worst-case: T(n)=T(1)+T(n−1)+Θ(n)T(n) = T(1) + T(n - 1) + \Theta(n)T(n)=T(1)+T(n−1)+Θ(n)
    2. Best-case:T(n)=T(n2)+T(n2)+Θ(n)=2∗T(n2)+Θ(n)T(n) = T(\frac{n}{2}) + T(\frac{n}{2}) + \Theta(n) = 2 *T(\frac{n}{2}) + \Theta(n)T(n)=T(2n​)+T(2n​)+Θ(n)=2∗T(2n​)+Θ(n)
    3. General-case ("Randomized Partition"):
      • Randomly generate an integer ( i ) between ( 1 ) to ( n ).
      • Use ( A[i] ) as pivot to do the partition.

    Recurrence relation here:

    T(n)=T(n16)+T(15n16)+Θ(n)T(n) = T\left(\frac{n}{16}\right) + T\left(\frac{15n}{16}\right) + \Theta(n) T(n)=T(16n​)+T(1615n​)+Θ(n)
