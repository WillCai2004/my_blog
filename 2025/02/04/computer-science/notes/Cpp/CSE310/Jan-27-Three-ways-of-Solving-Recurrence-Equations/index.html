# Three ways of Solving Recurrence Equations

# Recursion tree

  • Recursion Tree means to keep expanding the recurrence equation by replacing its left-hand side by right hand side until reaching the base case.

# Here is a typical form of Recurrence Equation:

T(n)=T(n2)+T(n4)+nT(n)=T(\frac{n}{2})+T(\frac{n}{4})+nT(n)=T(2n​)+T(4n​)+n

# Equation Explanation

  • T(n)T(n)T(n) is the time complexity of the algorithm.
  • When the problem has a size nnn, it is divided into two subproblems: one of size n2\frac{n}{2}2n​​ and another of size n4\frac{n}{4}4n​​. The time required to solve these subproblems is T(n2)T(\frac{n}{2})T(2n​) and T(n4)T(\frac{n}{4})T(4n​), respectively.
  • Apart from solving the subproblems, the algorithm performs an additional amount of work proportional to nnn, which could involve merging, sorting, or some other operations.
  • The recursion continues by breaking the subproblems further until a base case is reached, usually when n=1n=1n=1 or a very small size.

# Substation method

# Recurrence Equation Example:

T(n)=T(n)+1T(n) = T(\sqrt{n}) + 1T(n)=T(n​)+1

# Substation method Steps:

  1. Guess a solution first.
  2. Use mathematical induction to prove your guess is correct.
  3. Trial-and-error.

# Derivation

  1. Start with:
    T(n) = T(\sqrt{n}) + 1 \tag{\#0}
  2. Let k=log⁡2n  ⟹  n=2kk = \log_2 n \implies n = 2^{k}k=log2​n⟹n=2k
  3. Define S(k)=T(n)=T(2k)S(k) = T(n) = T(2^k)S(k)=T(n)=T(2k):
    S\left(\frac{k}{2}\right) = T\left(2^{k/2}\right) \tag{\#1}
  4. From #0, substitute:
    S(k) = T(n) = T(\sqrt{n}) + 1 = T(2^{k/2}) + 1 = S\left(\frac{k}{2}\right) + 1 \tag{\#2}
  5. Recurrence relation for S(k):
    S(k) = S\left(\frac{k}{2}\right) + 1 \tag{\#3}

# Recurrence Tree

  • Expand S(k) as a recursion tree:
  • Each level contributes a constant 1 to the total.
  • Total levels of recursion:

L=log⁡2k=log⁡2(log⁡2n)L = \log_2 k = \log_2 (\log_2 n) L=log2​k=log2​(log2​n)

# Solution

  1. From the recursion tree:
    T(n)=Θ(log⁡2(log⁡2n))T(n) = \Theta(\log_2 (\log_2 n))T(n)=Θ(log2​(log2​n))
  2. Using S(k)=T(n)S(k) = T(n)S(k)=T(n):
    T(n)=Θ(log⁡2(log⁡2n))T(n) = \Theta(\log_2 (\log_2 n))T(n)=Θ(log2​(log2​n))

# Master's method

# Definition of Master's method:

  • Master method is a "cook book" for solving one type of recurrence equation

T(n)=a∗T(nb)+f(n)(a≥1,b>1)T(n)=a*T(\frac{n}{b})+f(n) (a≥1, b>1) T(n)=a∗T(bn​)+f(n)(a≥1,b>1)

  • Change the original problem size nnn into a(a≥1)a (a≥1)a(a≥1) sub-problems, each of equal size (nb)(b>1)(\frac{n}{b})(b>1)(bn​)(b>1)

# Limitations of Master's method:

  • If f(n)f(n)f(n) is non-polynomial function, such as exponential, then master's method can't be applied
    • Exclusion Example: T(n)=T(n2)+2nT(n)=T(\frac{n}{2})+2^{n}T(n)=T(2n​)+2n
  • If f(n)f(n)f(n) is monotone functions, such as sin(n)sin(n)sin(n),cos(n)cos(n)cos(n), then master's method can't be applied.
    • Exclusion Example: T(n)=2∗T(n4)+sin(n)T(n)=2*T(\frac{n}{4})+sin(n)T(n)=2∗T(4n​)+sin(n)
  • Special form of master's method
    • Exclusion Example: T(n)=a∗T(nb)+θ(nklog⁡pn)T(n)=a*T(\frac{n}{b})+\theta(n^{k}\log^{p}n)T(n)=a∗T(bn​)+θ(nklogpn)
      In this class, you're NOT allowed to use above to solve a recurrence equation

# Application:

# Always compare two functions:

nlogban^{log_{b} a}nlogb​a and f(n)f(n)f(n)

# General conclusion:

  • Which ever function is an upper bound of another one, that function becomes tight bound for T(n)T(n)T(n). If the two functions have exactly the same growth rate, then T(n)=θ(f(n)∗logn)=θ(nlogba∗log2n)T(n)=\theta(f(n)*log n)=\theta(n^{log_{b}a}*log_{2}n)T(n)=θ(f(n)∗logn)=θ(nlogb​a∗log2​n)

# Case #1: nlog⁡ba>f(n)n^{\log_b a} > f(n)nlogb​a>f(n)

  • f(n)=O(nlog⁡ba−ϵ)(ϵ>0)f(n) = O(n^{\log_b a - \epsilon}) \quad (\epsilon > 0)f(n)=O(nlogb​a−ϵ)(ϵ>0)

    • nlog⁡ban^{\log_b a}nlogb​a is an upper bound of f(n)f(n)f(n).
    • nlog⁡ban^{\log_b a}nlogb​a is only larger than f(n)f(n)f(n) by a constant polynomial factor.

  • Then:

    T(n)=Θ(nlog⁡ba)T(n) = \Theta(n^{\log_b a}) T(n)=Θ(nlogb​a)

# Case #2: nlog⁡ba=f(n)n^{\log_b a} = f(n)nlogb​a=f(n)

  • nlog⁡ban^{\log_b a}nlogb​a and f(n)f(n)f(n) have the same growth rate.

  • Then:

    T(n)=Θ(f(n)⋅log⁡n)=Θ(nlog⁡ba⋅log⁡n)T(n) = \Theta(f(n) \cdot \log n) = \Theta(n^{\log_b a} \cdot \log n) T(n)=Θ(f(n)⋅logn)=Θ(nlogb​a⋅logn)

# Case #3: nlog⁡ba<f(n)n^{\log_b a} < f(n)nlogb​a<f(n)

  • nlog⁡ban^{\log_b a}nlogb​a is a lower bound of f(n)f(n)f(n).

  • f(n)=Ω(nlog⁡ba+ϵ)(ϵ>0)f(n) = \Omega(n^{\log_b a + \epsilon}) \quad (\epsilon > 0)f(n)=Ω(nlogb​a+ϵ)(ϵ>0)

    • f(n)f(n)f(n) is only larger in a constant polynomial factor than nlog⁡ban^{\log_b a}nlogb​a.

  • Then:

    T(n)=Θ(f(n))T(n) = \Theta(f(n)) T(n)=Θ(f(n))

# Additional Note

  • "Regularity Rule": The conditions above assume that f(n)f(n)f(n) satisfies certain regularity properties, such as being polynomialy larger or smaller than nlog⁡ban^{\log_b a}nlogb​a.
