# Three Master Method Cases

# General Form

The recurrence relation is given as:

T(n)=a⋅T(nb)+f(n)T(n) = a \cdot T\left(\frac{n}{b}\right) + f(n) T(n)=a⋅T(bn​)+f(n)

  • a>1a > 1a>1: number of subproblems
  • b>1b > 1b>1: factor by which the input size is divided
  • f(n)f(n)f(n): additional work outside the recursive calls
  • nlog⁡ban^{\log_b a}nlogb​a: the threshold function

# Case #1: f(n)=O(nlog⁡ba−ϵ), ϵ>0f(n) = O\big(n^{\log_b a - \epsilon}\big), \, \epsilon > 0f(n)=O(nlogb​a−ϵ),ϵ>0

  • Condition: f(n)f(n)f(n) grows asymptotically slower than nlog⁡ban^{\log_b a}nlogb​a.
  • Explanation: The additional work f(n)f(n)f(n) is dominated by the contribution from the recursive subproblems.
  • Result:

    T(n)=Θ(nlog⁡ba)T(n) = \Theta\big(n^{\log_b a}\big) T(n)=Θ(nlogb​a)

# Case #2: f(n)=Θ(nlog⁡ba)f(n) = \Theta\big(n^{\log_b a}\big)f(n)=Θ(nlogb​a)

  • Condition: f(n)f(n)f(n) grows at the same rate as nlog⁡ban^{\log_b a}nlogb​a.
  • Explanation: The work from the recursive subproblems and the additional work f(n)f(n)f(n) contribute equally.
  • Result:

    T(n)=Θ(nlog⁡ba⋅log⁡n)T(n) = \Theta\big(n^{\log_b a} \cdot \log n\big) T(n)=Θ(nlogb​a⋅logn)

# Case #3: f(n)=Ω(nlog⁡ba+ϵ), ϵ>0f(n) = \Omega\big(n^{\log_b a + \epsilon}\big), \, \epsilon > 0f(n)=Ω(nlogb​a+ϵ),ϵ>0

  • Condition: f(n)f(n)f(n) grows asymptotically faster than nlog⁡ban^{\log_b a}nlogb​a, but satisfies the regularity condition:

    a⋅f(nb)≤c⋅f(n),for some constant c<1.a \cdot f\left(\frac{n}{b}\right) \leq c \cdot f(n), \quad \text{for some constant } c < 1. a⋅f(bn​)≤c⋅f(n),for some constant c<1.

  • Explanation: The additional work f(n)f(n)f(n) dominates the contribution from the recursive subproblems.
  • Result:

    T(n)=Θ(f(n))T(n) = \Theta\big(f(n)\big) T(n)=Θ(f(n))

# Regularity Condition

For Case #3 to apply, the function f(n)f(n)f(n) must satisfy the regularity condition:

a⋅f(nb)≤c⋅f(n),for some constant c<1.a \cdot f\left(\frac{n}{b}\right) \leq c \cdot f(n), \quad \text{for some constant } c < 1. a⋅f(bn​)≤c⋅f(n),for some constant c<1.

This ensures f(n)f(n)f(n) is "smooth" enough to dominate nlog⁡ban^{\log_b a}nlogb​a.

# General Framework for Divide-and-Conquer

  1. Identify how to divide the problem into smaller sub-problems.
  2. Determine the base case (when the problem size is small, how to solve it).
  3. Figure out how to combine the result of sub-problems.

# Example: Maximum Sum Subarray Problem

Input: A[1…n]A[1 \dots n]A[1…n] (an array of integers).
Output: A subarray A[i…j]A[i \dots j]A[i…j] such that 1≤i≤j≤n1 \leq i \leq j \leq n1≤i≤j≤n and: sum(i,j)=∑k=ijA[k]\text{sum}(i, j) = \sum_{k=i}^j A[k]sum(i,j)=∑k=ij​A[k] is maximized.

# Example Array:

A = [3, -4, 5, -2, -2, 6, -3, 5, -3, 2]
For the subarray A[3…8]A[3 \dots 8]A[3…8]:

sum(3,8)=5+(−2)+(−2)+6+(−3)+5=9\text{sum}(3, 8) = 5 + (-2) + (-2) + 6 + (-3) + 5 = 9 sum(3,8)=5+(−2)+(−2)+6+(−3)+5=9

Time Complexity: Θ(n2)\Theta(n^2)Θ(n2)

# Algorithm B: Divide-and-Conquer

  • Steps:

    1. Divide the array into two halves.
    2. Solve for the left half and the right half recursively.
    3. Combine the results to find the maximum subarray crossing the middle.

  • Example Array Division:
    A = [3, -4, 5, -2, -2, 6, -3, 5, -3, 2]
    Divide into:

  • Left: [3,−4,5,−2,−2][3, -4, 5, -2, -2][3,−4,5,−2,−2], result: 555

  • Right: [6,−3,5,−3,2][6, -3, 5, -3, 2][6,−3,5,−3,2], result: 888

  • Time Complexity: Θ(nlog⁡n)\Theta(n \log n)Θ(nlogn)

# Algorithm C: Dynamic Programming (Kadane's Algorithm)

  • Steps:

    • Maintain a running sum for the current subarray.
    • Reset the sum to 0 if it becomes negative, and track the maximum sum so far.

  • Time Complexity: Θ(n)\Theta(n)Θ(n)
