Pocket Payload

the first stage will accept only 0xc = 12 Byte of shellcode into an RWX region (at the fixed address 0x28a42000 ). 12 bytes won’t be able to do the job for you → use a small stage1 to build a rop environment & then SROP to execute execve("cat", "/flag") .

# 1. Mechanics of the challenge

  • a total of 12 bytes of shellcode will be landed on a fixed RWX page at 0x28a42000 (that mapping isn’t randomized by PIE).
  • read the flag once you have executed.

# 2. Main idea

Use the 12 bytes as both stage1 + a gadget pool simultaneously: read a rop chain to the stack → ret into the chain → write to leak a stack address → read again to load an SROP frame → rt_sigreturn to control every register → execve .

12-Byte stage1 (tail instructions double as gadgets):

Since we have a fixed RWX address, we know what our gadget addresses are:

the chain:

  1. stage1 read(0, rsp, …) reads a rop chain to the stack, then enters it via ret .
  2. Rop: write(1, rsi, rdx) leaks stack contents -> derive current stack base.
  3. Rop: read(0, rsi, …) again to load SROP payload (full sigcontext).
  4. pop rax; ret -> rax=15, syscall; ret -> rt_sigreturn , with forged registers executing: execve("/run/dojo/bin/cat", ["/run/dojo/bin/cat", "/flag", NULL], NULL) .

# 3. Key points/pitfalls

  • stage1 tail is gadget set: 58 c3 , 5f c3 , 0f 05 c3 -- all three gadgets live within those same 12 bytes. There’s no dependency on external binary and no hunting for gadgets.
  • stack address recovery: after the write leak, real stack base = stack_base - 0xb0 (subtract a fixed offset from the leaked value). SROP frame involves cat/flag/argv addresses are all calculated off of this one.
  • SROP sets every register at once: rt_sigreturn (syscall 15), restores rax/rdi/rsi/rdx/rip from on-stack sigcontext assembles execve call directly bypasses "12 bytes can't lay out arguments to execve".

# 4. Takeaways

  • tiny stage1 = read + built-in gadgets: with stage1 located at a fixed RWX address, reuse pop;ret / syscall; ret at stage1 tail as rop pool -- 12 bytes enough bootstrap arbitrarily long rop.
  • leak -> SROP -> execve: without string available “/bin/sh” , SROP directly into execve(cat, [cat,/flag]) is simpler than laying out execve’s arguments , rt_sigreturn is lever “set every register with one syscall”.
