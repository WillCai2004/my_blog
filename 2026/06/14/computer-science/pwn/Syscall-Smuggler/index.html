Syscall Smuggler

pwn.college · Shellcoding Challenges
Write shellcode that reads /flag , however the input may NOT include any of the following sequences of bytes related to system calls: syscall ( 0f 05 ), sysenter ( 0f 34 ), or int ( cd 80 ). The trick to get around this: self-modifying code, i.e., submit an input sequence that is very close to being a syscall sequence, and when run-time occurs +1 that into a true 0f 05 .

# 1. Mechanics of the problem

Input to the filter will pass as long as it does not have the machine code for syscall ( 0f 05 ) in it. Therefore the state of the input cannot have 0f 05 inside of it.

# 2. Main idea

Take advantage of the difference between what is being filtered on ("the static bytes") versus what runs ("the dynamic bytes"):

  • Put 0f 04 in your input (it is not a syscall, therefore it should pass the filter).
  • At the beginning of your shellcode, write inc byte ptr [rip+offset] . This adds one to the 04 , thus at run time it turns into 0f 05 .
  • Now that we've modified the original 0f 05 c3 ( syscall; ret ), we just need to follow it through to our patched version ( 0f 04 c3 -> 0f 05 c3 ).

Logic: open("/flag", 0) -> read(fd, rsp, 0x7f) -> write(1, rsp, 0x7f) , where each call to a syscall goes through that self modifed stub ( 0f 04 c3 -> 0f 05 c3 ).

# 3. Points to avoid / important details

  • Filter only looks at static input bytes, not dynamic bytes: therefore by splitting up 0f 05 into "0f 04" + a runtime inc , you are well within bounds of its inspection.
  • inc byte [rip+disp] ( fe 05 .. ) references the pseudo-syscall byte at the end of your pseudo-instruction, once it's been modified, either use call to jump back there, or simply continue to execute (after modifying).
  • There is no byte black list on this challenge so REX.W is allowed -- it employs mov rax, imm64 ( 48 b8 .. ) to fill in a reference to /flag . (Compare w/Ello Ackers where 0x48 was disallowed).

# 4. Takeaways

  • Shellcode which modifies itself: solution to a "static byte filter" -- submit a legitimate near miss and modify it into the forbidden instruction at run-time. inc / add / xor can all be employed to restore the target byte.
  • Reusable syscall stub: treat 0f 05 c3 as a small function you can call over and over again. It conserves space and limits the self modification to a single location.
